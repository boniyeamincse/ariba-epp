# Deployment Documentation

Deployment topologies, hardening and operational runbooks.

Planned contents:

- Local development with Docker Compose.
- Pilot and production topology and network segmentation.
- TLS, secrets management, backup/restore and upgrade/rollback runbooks.
- Monitoring, health checks and incident procedures.
- Sizing methodology based on measured event rate and retention.

Production readiness requires review and evidence. Docker Compose alone is not a
production security or high-availability guarantee.
