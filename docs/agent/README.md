# Agent Documentation

Design and operations material for the Windows and Linux agents.

Planned contents:

- Supported OS matrix and per-platform telemetry coverage.
- Enrollment, certificate renewal, rotation and revocation flows.
- Collector design, resource budgets and offline queue behavior.
- Secure uninstall, recovery and anti-tamper procedures.
- Packaging: MSI for Windows, DEB/RPM for Linux.

Do not claim portable telemetry semantics across platforms; document
OS-specific behavior explicitly.
