# Security Documentation

Security design, privacy and safeguarding material.

Planned contents:

- Threat model and trust boundaries.
- Authentication, MFA, RBAC and tenant/site authorization.
- Agent identity, mutual TLS, certificate lifecycle and secret rotation.
- Signed updates and policy verification.
- Response-action safeguards: approval, target validation, expiry, audit and rollback.
- Telemetry privacy, retention, data residency and access control.
- Quarantine and evidence handling.

Do not claim compliance, certification or penetration-test status without
evidence.
